⚙️ Migiro Motors Admin

Manage stock and web content

This admin panel is ready for two people to manage Migiro Motors from phone or desktop with Netlify Identity and Git Gateway.

  • Manage vehicle stock in data/inventory.json
  • Customer enquiries are sent through Netlify Forms
  • Use Netlify Identity → Invite users to add the second manager
  • Editorial workflow is enabled for safer review and publishing

Netlify steps: Enable Identity, enable Git Gateway, invite both managers, then open /admin/.
